## 1. نظرة عامة
نبني إضافة متصفحات Chromium (متوافقة مع Manifest V3 على Chrome و Edge و Brave) تُدعى **Web Scrolling Screenshot**. تهدف الإضافة إلى حل مشكلة شائعة في أدوات التصوير الحالية: التشويش (Blur) على شاشات Retina/High-DPI، تكرار القوائم الثابتة (`sticky/fixed headers`) في كل لقطة، وبطء أو تعطل الصفحات الطويلة، أو فرض علامات مائية وقيود على عدد اللقطات.

تحقق الإضافة ثلاثة مخرجات رئيسية:
1. **دقة بصرية فائقة (High-DPI Native):** التقاط ودمج بكسل-لبكسل وفق `window.devicePixelRatio` الفعلي بدون أي تقليص غير مقصود.
2. **مرونة الالتقاط:** التقاط الصفحة كاملة تلقائياً، أو تحديد مساحة حرة بالسحب بالماوس (حتى لو امتدت أطول من ارتفاع الشاشة عبر التمرير التلقائي).
3. **خصوصية وتحكم كامل:** معالجة محلية 100% على جهاز المستخدم، بدون حسابات أو خوادم أو تتبع، مع شاشة معاينة مستقلة وتصدير فوري بصيغ عالية الجودة.

## 2. الأهداف ومؤشرات النجاح القابلة للقياس
| الهدف | مقياس التحقق | القيمة المستهدفة |
|---|---|---|

| قبول متجر Chrome بدون تعقيدات | قائمة الصلاحيات في `manifest.json` | 0 صلاحيات مضيف واسعة (`<all_urls>`)، وصلاحيات محدودة فقط |

## 4. نطاق المشروع (Scope)

### داخل النطاق (الإطلاق الأول — MVP)
- **التقاط الصفحة كاملة (`Full Page Capture`):** تمرير تلقائي ذكي، إخفاء العناصر الثابتة (`position: fixed / sticky`) بعد الشريحة الأولى وإعادتها بدقة فور الانتهاء، ومعالجة الصور الكسولة (`loading="lazy"`).
- **التقاط جزء محدد بالسحب (`Region Selection Capture`):** طبقة تحديد معزولة (`Shadow DOM`) تتيح سحب مستطيل بالماوس مع عرض الأبعاد لحظياً ودعم **التمرير التلقائي** عند اقتراب المؤشر من حافة الشاشة لالتقاط مناطق أطول من الشاشة، مع إلغاء فوري بزر `Esc`.
- **شاشة المعاينة (`Preview Tab`):** تفتح تلقائياً في تبويب جديد بعد الالتقاط؛ تعرض الصورة مع تكبير/تصغير (`Fit to Width`, `100% 1:1`, Zoom slider)، أبعاد الصورة بالبكسل، والحجم التقديري.
- **التصدير والحفظ:**
  - تنزيل **PNG غير مضغوط (Lossless)**.
  - تنزيل **JPEG** أو **WebP** مع شريط اختيار الجودة (من 60% إلى 100%).
  - دعم التنزيل المتعدد التلقائي إذا انقسمت الصفحة فائقة الطول لأكثر من جزء.
- **تعدد اللغات (`_locales`):** العربية (مع تخطيط RTL كامل) والإنجليزية (LTR)، مع استمرار الواجهة متجاوبة ونظيفة.
- **تخصيص الاسم والوقت:** تسمية تلقائية واضحة مثل `screenshot-domain-YYYYMMDD-HHmmss.png`.

### مؤجّل لما بعد الإطلاق (Post-Launch — بقرار المالك)
- النسخ المباشر للحافظة (`Copy to Clipboard`) وأداة القص داخل شاشة المعاينة (`In-preview Crop`).
- التقاط عنصر DOM محدد بالتحويم (`DOM Element Picker`).
- محرر رسومات بسيط (أسهم، مستطيلات، نصوص، أداة إخفاء/Blur).
- التصدير إلى ملف PDF (صفحة واحدة متصلة أو مقسمة A4).
- وضع `CDP Ultra-HD` الاختياري عبر `chrome.debugger` لتصوير صفحات بتكبير قسري يتجاوز DPR الشاشة.

### خارج النطاق نهائياً (Out of Scope)
- حسابات المستخدمين، تسجيل الدخول، أو أي اشتراكات مدفوعة مقيدة.
- رفع الصور إلى أي خادم خارجي أو سحابة، أو جمع أي بيانات تحليلية (`Zero Telemetry`).
- وضع علامات مائية (Watermarks) أو فرض حد أقصى لعدد اللقطات.

## 5. المتطلبات الوظيفية التفصيلية

### 5.1 النافذة المنبثقة (`Popup`)
- زر **«التقاط الصفحة كاملة»** وزر **«تحديد مساحة للتصوير»** واضحان مع اختصارات لوحة المفاتيح.
- اختيار الصيغة الافتراضية المفضلة (`PNG` / `JPEG` / `WebP`) وجودة الضغط وحفظها في `chrome.storage.local`.
- عرض حالة التقدم أثناء التمرير (مثل: `45%` أو شريط تقدم حي) وزر إيقاف/إلغاء أثناء الالتقاط الطويل.
- رسائل خطأ واضحة ومترجمة عند فتح صفحات محمية من المتصفح مثل `chrome://` أو `Chrome Web Store`.

### 5.2 محرك التمرير والالتقاط (`Scroll & Capture Engine`)
- حساب أبعاد الصفحة بدقة (`scrollWidth`, `scrollHeight`, `innerWidth`, `innerHeight`, `devicePixelRatio`).
- احترام مهلة استدعاءات المتصفح لـ `captureVisibleTab` (بما يمنع خطأ Chrome: `MAX_CAPTURE_VISIBLE_TAB_CALLS_PER_SECOND`) مع وتيرة التقاط ذكية وسريعة.
- تعطيل `scroll-behavior: smooth` مؤقتاً أثناء الالتقاط حتى يتم الانتقال بين الشرائح فوراً وبدقة بكسل تامة، ثم استعادته بعد الانتهاء.
- كشف العناصر المثبتة (`fixed` / `sticky`) وإخفاؤها بصرياً (`visibility: hidden`) بعد الشريحة الأولى فقط ثم إعادتها فور الانتهاء.
- تقسيم اللقطة تلقائياً في `OffscreenCanvas` إذا تجاوز الارتفاع الفعلي بالبكسل الحد الآمن (16,384 بكسل مبدئياً) لمنع تلف الصورة.

### 5.3 أداة تحديد المساحة الحرة (`Region Selector`)
- حقن واجهة التحديد داخل `Shadow DOM` معزول تماماً عن أنماط CSS الخاصة بالموقع المستهدف.
- إتاحة السحب بالماوس لتحديد المستطيل المطلوب، وتمرير الصفحة تلقائياً إذا سُحب المؤشر لأسفل أو أعلى حافة نافذة العرض.
- عرض شريط معلومات صغير بجانب التحديد يوضح العرض × الارتفاع بالبكسل وتلميح `Esc للإلغاء`.

### 5.4 شاشة المعاينة والتصدير (`Preview Tab`)
- استقبال الشرائح المدمجة بأمان عبر بيانات Blob / IndexedDB مؤقتة محلية (تُحذف تلقائياً عند إغلاق تبويب المعاينة لتوفير الذاكرة).
- تبديل العرض بين `ملائمة العرض (Fit)` و `الحجم الحقيقي (1:1 Pixel)` والتكبير حتى `400%`.
- أزرار تنزيل فوري بصيغة PNG أو التحويل الحي لـ JPEG/WebP بجودة مختارة.

## 6. المتطلبات غير الوظيفية
| المجال | المتطلب |
|---|---|
| **الأداء** | التزام ميزانية الذاكرة: تفريغ شرائح الـ Bitmap المؤقتة فور دمجها (`ImageBitmap.close()`). |
| **الأمان والخصوصية** | تطبيق مبدأ أقل الصلاحيات في [`SECURITY.md`](SECURITY.md)، لا اتصالات خارجية، لا `eval` أو أكواد ديناميكية. |
| **إتاحة الوصول (a11y)** | تباين ألوان WCAG AA، دعم كامل للوحة المفاتيح (`Tab`, `Enter`, `Esc`)، وتسميات ARIA لجميع الأزرار. |
| **التوافق** | متصفحات Chromium (Chrome ≥ 120، Edge ≥ 120، Brave) على Windows / macOS / Linux. |
| **الصيانة والاختبار** | تغطية اختبارات الوحدة لمنطق الحساب والدمج + اختبارات Playwright في متصفح حقيقي على صفحات طويلة و RTL. |

## 7. قصص المستخدم ومعايير القبول الرئيسية
1. **كمستخدم، أريد التقاط صفحة مقال أو توثيق طويلة بنقرة واحدة.**
   - *معيار القبول:* عند الضغط على «التقاط الصفحة كاملة»، تمرر الإضافة الصفحة وتفتح تبويب المعاينة بصورة متصلة خالية من التكرار أو الفواصل، مطابقة تماماً للعرض الأصلي عند نسبة التكبير `1:1`.
2. **كمطوّر، أريد تحديد قسم محدد من صفحة يتجاوز طول الشاشة بالماوس.**
   - *معيار القبول:* عند اختيار «تحديد مساحة» والسحب لأسفل حافة المتصفح، تتمرر الصفحة بسلاسة ويتسع التحديد؛ وعند الإفلات تُلتقط وتُقص المنطقة المحددة فقط بدقة High-DPI.
3. **كمستخدم عربي، أريد استخدام الواجهة بلغتي بدون مشاكل في الاتجاه.**
   - *معيار القبول:* عند ضبط لغة المتصفح على العربية، تظهر النوافذ وشاشة المعاينة بتخطيط RTL صحيح وعبارات عربية واضحة دون تداخل نصوص أو أيقونات معكوسة.
