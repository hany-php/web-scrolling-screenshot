# Chrome Web Store & Edge Add-ons Submission Guide

## Single Purpose Statement

Capture full-page scrolling screenshots and drag-to-select regions (including tall scrollable sections) at native High-DPI resolution, preview them with zoom controls, and export locally as PNG, JPEG, or WebP.

## Permission Justifications

| Permission  | Reviewer Justification                                                                                                                  |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `activeTab` | Temporarily capture the visible viewport of the active tab only when the user explicitly clicks capture or uses a keyboard shortcut.    |
| `scripting` | Inject the scroll orchestrator and Shadow DOM region selector into the active page on demand without persistent global content scripts. |
| `offscreen` | Host `OffscreenCanvas` in MV3 to stitch High-DPI viewport frames and encode JPEG/WebP images without blocking the popup or service UI.  |
| `downloads` | Save exported PNG, JPEG, or WebP screenshots with clean sanitized filenames (`screenshot-<domain>-<timestamp>.ext`).                    |
| `storage`   | Store local user preferences only: default export format, quality percentage, and Arabic/English UI language selection.                 |
