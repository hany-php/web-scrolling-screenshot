# الأسئلة المفتوحة والقرارات المؤقتة (OPEN-QUESTIONS)

يحتاج كل سؤال هنا إلى قرار من المالك قبل أو أثناء المرحلة المحددة. عند الحسم، نحدّث الوثيقة المعنية (أو ننشئ ADR) ونضع علامة `✅` مع نص القرار النهائي.
